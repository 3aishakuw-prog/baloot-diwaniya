# بلوت الديوانية

لعبة بلوت كاملة للجوال: أوفلاين ضد الكمبيوتر، أونلاين مع لاعبين، وحسابات تسجيل دخول.

## وش فيها

- **قوانين البلوت كاملة:** حكم وصن وأشكل، اللفة الثانية (حكم ثاني / ولا)، الدبل والثري والفور والقهوة (مع المقفول)، المشاريع (سرا، خمسين، مية، أربعمية) والبلوت، الأرض، الخسرانة، الكبوت، وسوا.
- **الكمبيوتر بثلاث مستويات:** سهل، متوسط، وصعب (يحسب الورق اللي نزل ويحلل الاحتمالات قبل كل ورقة).
- **أونلاين:**
  - لعب سريع: ندور لك لاعبين، وإذا ما اكتملت الطاولة خلال 15 ثانية يكملها الكمبيوتر.
  - غرف خاصة بكود من 4 حروف ورابط دعوة، وصاحب الغرفة يقدر يضيف كمبيوتر للأماكن الفاضية.
  - مؤقت للدور، وإذا انقطع النت الكمبيوتر يلعب عنك لين ترجع وتكمل من نفس المكان.
  - سوالف وإيموجي جاهزة (بدون كتابة حرة، مناسبة لكل الأعمار).
- **الحسابات:** تسجيل باسم مستخدم وكلمة مرور، أو دخول كضيف، مع مستويات وخبرة وإحصائيات وترتيب اللاعبين.
- **تطبيق قابل للتثبيت (PWA):** بعد أول فتح يشتغل بدون نت ضد الكمبيوتر، وجاهز يتحول لتطبيق أندرويد على Google Play.

## التشغيل على جهازك

يحتاج Node.js نسخة 18 أو أحدث.

```
npm install
npm start
```

افتح `http://localhost:3000`

## النشر على Render

1. ارفع هالمجلد على GitHub في repo جديد.
2. في Render اختر **New → Web Service** واربطه بالـrepo.
3. أوامر البناء والتشغيل:
   - Build Command: `npm install`
   - Start Command: `npm start`

   (أو اختر **New → Blueprint** ويقرأ ملف `render.yaml` تلقائياً.)
4. بعد النشر يعطيك رابط ثابت مثل `https://baloot-diwaniya.onrender.com`.

**مهم عن الحسابات:** الخطة المجانية في Render تمسح ملفات السيرفر مع كل نشر أو إعادة تشغيل، يعني الحسابات والإحصائيات تنمسح. عشان تثبت:

- أضف Disk من إعدادات الخدمة على المسار `/var/data`، وحط متغير البيئة `DATA_DIR=/var/data` (الـDisk يحتاج خطة مدفوعة)، أو
- استخدم استضافة فيها تخزين دائم.

وانتبه إن الخدمة المجانية تنام بعد 15 دقيقة بدون زوار، وأول فتح بعدها ياخذ قريب دقيقة.

## على الآيفون

افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. يصير له أيقونة ويفتح كتطبيق.

## تحويله لتطبيق أندرويد على Google Play

1. افتح [pwabuilder.com](https://www.pwabuilder.com) وحط رابط اللعبة بعد النشر.
2. اختر **Android ← Generate Package** وحمّل الملفات (فيها ملف AAB للرفع، وملف `assetlinks.json`).
3. في Render أضف متغير بيئة اسمه `ASSETLINKS_JSON` وحط فيه محتوى ملف `assetlinks.json` كامل. السيرفر يعرضه تلقائياً على `/.well-known/assetlinks.json`، وهذا اللي يخلي التطبيق يفتح بدون شريط المتصفح.
4. في Google Play Console أنشئ تطبيق جديد وارفع ملف الـAAB.

## الملفات

| الملف | وش يسوي |
|---|---|
| `shared/engine.js` | قوانين اللعبة والحساب (نفس الكود يشتغل في الجوال والسيرفر) |
| `shared/bot.js` | الكمبيوتر بالمستويات الثلاث |
| `shared/host.js` | إدارة الأدوار والمؤقت والكمبيوتر |
| `server/server.js` | السيرفر: الحسابات والغرف واللعب السريع |
| `server/store.js` | حفظ الحسابات في ملف `data/db.json` |
| `public/` | التطبيق نفسه: الشاشات والتصميم والأصوات والأيقونات |
| `test/sim.js` | اختبار يلعب مئات الصكات ويتأكد من القوانين والحساب (`npm test`) |

## متغيرات البيئة

| المتغير | الاستخدام |
|---|---|
| `PORT` | منفذ السيرفر (Render يحطه تلقائياً) |
| `DATA_DIR` | مكان ملف الحسابات (حطه على Disk دائم) |
| `QUICK_WAIT_MS` | كم ينتظر اللعب السريع قبل ما يكمل بالكمبيوتر (الافتراضي 15000) |
| `ASSETLINKS_JSON` | محتوى ملف assetlinks.json لتطبيق Google Play |

## ملاحظات

- الدخول بحساب قوقل أو برقم الجوال يحتاج مفاتيح خاصة (Google OAuth أو مزود رسائل SMS)، تقدر تضيفها لاحقاً.
- الأصوات مولّدة بالكود، والورق والتصميم كلها رسومات أصلية، فما فيه ملفات خارجية تحتاج حقوق.
